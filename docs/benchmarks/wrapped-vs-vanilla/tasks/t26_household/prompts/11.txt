Small one: the expense list is getting long, so add `--payer NAME` to
`expense list`. With it, only the expenses paid by that member are printed,
in the same format and id order as before (NAME matches case-insensitively;
an unknown name is `error: unknown member: NAME`; if that member paid
nothing it prints `No expenses.`). Without `--payer` nothing changes.
