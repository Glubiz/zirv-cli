Composer key contract. Enter submits (or queues, mid-turn). Shift+Enter / Alt+Enter inserts a newline. ↑/↓ walk submit history only at the first/last visual line of the draft (so mid-draft cursoring never fights history). @ opens an inline repository file-reference hint resolved against the workdir. Bracketed paste — or, on a terminal without it, large same-tick input coalescing — inserts as one block, never one Enter per pasted line.
Follow mode. The transcript auto-scrolls to the newest event while follow is on. Any scroll-up disengages it — new tool output no longer yanks the viewport — and it silently re-engages once the operator scrolls back to the bottom. Focus, selection, expanded tool calls and the draft all survive a resize and continued streaming.
Approvals stay separate. A blocked/approval-required state is shown in the transcript and status line, but the composer never doubles as the approval control — queued composer input is held (and persisted) rather than ever being submitted as an approval answer.
Mixed panes. A wrapped harness pane keeps its PTY/vt100 rendering and raw-mode input path unchanged. Native controls (composer, expand/collapse, queue/steer/interrupt) are offered only when the focused pane's kind is Native; a wrapped pane's key hints and input routing are untouched.
