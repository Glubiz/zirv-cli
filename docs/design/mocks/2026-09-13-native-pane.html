Native pane — N21 (#490)

The native pane modelled on Claude Code's interactive UI: ⏺ assistant and tool bullets with ⎿ result tree lines, > user lines on a shaded background, a bordered composer with a hint line, a spinner line with verb/elapsed/tokens, numbered approval dialogs, unified diffs with line numbers, and /, @ and ! entry modes. Zirv's own dashboard chrome — header chip, fixed sidebar, footer key line — stays around the pane. Every glyph carries state without relying on colour: ⏵ running, ⏸ blocked, ⚑ approval, ✔ done, • unread, ✖ failed, ⧗ queued, ◍ draining.

Rendered inline as ordinary ⏺ bullets so they scroll with the conversation, and mirrored into the status line. Drafts, selection, focus, scrollback and acknowledged input survive all three; a queued line is re-targeted to the logical seat's current session, never to the retired generation.

Slash commands, the file picker and the shell line (item 7)

The @ picker reuses the containment-safe path resolver, so it can only offer paths inside the pane's own worktree; ! runs through the pane's existing process tool under the same approval rules as any other tool call.
