Chocolatey Package Verification for zirv

PACKAGE CONTENTS
The Chocolatey package for zirv contains the following files:

1. tools/zirv.exe
   - The compiled Windows executable
   - Built from the official GitHub repository: https://github.com/Glubiz/zirv-cli
   - Placed in the tools directory by scripts/update_chocolatey.ps1

2. LICENSE.txt
   - MIT License for the project
   - Included in the package root and in the tools directory

3. VERIFICATION.txt
   - This file

BINARY VERIFICATION
To verify the integrity of the zirv.exe binary included in this package:

1. Identify the Release Version
   - Check the package version from Chocolatey: choco info zirv
   - Or review the installed package: Get-ChildItem "$env:ChocolateyInstall\lib\zirv\"

2. Download the Official Release Asset
   - Visit https://github.com/Glubiz/zirv-cli/releases
   - Find the release matching the package version
   - Download zirv-<version>-windows.exe and its accompanying zirv-<version>-windows.exe.sha256 checksum file
     (e.g., for version 4.9.0: zirv-4.9.0-windows.exe and zirv-4.9.0-windows.exe.sha256)

3. Verify the Checksum
   - Extract the expected SHA256 from the .sha256 file
   - Generate the checksum of the installed binary:
     Get-FileHash -Algorithm SHA256 "$env:ChocolateyInstall\lib\zirv\tools\zirv.exe"
   - Compare the checksums; they must match exactly

4. Build from Source (Alternative)
   You can also build the binary from source to verify:
   - Clone the repository: git clone https://github.com/Glubiz/zirv-cli.git
   - Build with Cargo: cargo build --release
   - The resulting binary can be found in target/release/zirv.exe
